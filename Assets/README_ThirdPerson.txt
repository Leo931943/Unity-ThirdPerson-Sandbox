# Unity 3D 第三人稱自由走動場景 (Third Person Sandbox)

## 🎮 場景功能特色
1. **第三人稱角色控制 (ThirdPersonController)**:
   - 依照相機視角進行 360 度全方向平滑移動 (WASD)。
   - 角色自動平滑旋轉至移動方向。
   - 支援行走 (Walk) 與衝刺快跑 (Sprint - 按住 Shift)。
   - 具備真實重力與下坡黏地判定，平滑上下階梯與斜坡。
   - 支援跳躍寬限 (Coyote Time) 與預先按跳緩衝 (Jump Buffer)。
   - 掉落邊界防護機制：若不慎跌落會自動重置回起點。

2. **第三人稱環繞相機 (ThirdPersonCamera)**:
   - 滑鼠水平與垂直環繞旋轉 (Yaw / Pitch)，並設定合理的俯仰角度限制。
   - 滑鼠滾輪即時拉近 / 拉遠視野 (Zoom)。
   - 相機防穿牆檢測 (SphereCast Collision Avoidance)：在靠近障礙物或牆面時相機會自動往前推，離開後自動還原距離。
   - 滑鼠指針自動鎖定與解鎖 (ESC 鍵切換)。

3. **3D 探索測試遊樂場 (Playground Environment)**:
   - 廣闊的主地表 (80m x 80m) 與外圍防護矮牆。
   - 斜坡測試區 (18度緩坡、30度陡坡)。
   - 階梯與觀景台 (測試 Step Offset 階梯攀爬)。
   - 跑酷浮島跳躍區 (由低到高連續 6 座平台)。
   - 拱門與石柱迷宮長廊 (測試轉角與遮擋穿牆防護)。
   - 散佈於場景各處的 8 顆發光旋轉收集水晶 (觸碰即收集)。

4. **即時 HUD 介面 (SimpleHUD)**:
   - 左上角：完整的鍵盤滑鼠操作按鍵說明。
   - 右上角：角色的即時移動速度、地面/滯空狀態與水晶收集進度。

---

## 🕹️ 操作方式
| 按鍵 | 操作動作 |
|---|---|
| **W / A / S / D** | 前後左右移動 (相對於鏡頭方位) |
| **Left Shift** | 按住進行衝刺快跑 |
| **Space (空白鍵)** | 跳躍 |
| **滑鼠移動** | 旋轉第三人稱鏡頭角度 |
| **滑鼠滾輪** | 拉近 / 拉遠相機距離 |
| **ESC 鍵** | 解除鎖定 / 鎖定滑鼠指標 |
| **R 鍵** | 立即重置玩家位置回起點 |

---

## 🚀 如何在 Unity 中開始？
1. 切換回 Unity 視窗，Unity 會自動編譯並載入腳本。
2. 在頂部功能表點擊：
   `Tools` -> `第三人稱場景 (Third Person)` -> `1. 一鍵建立完整遊玩場景 (Build Complete Scene)`
   *(若尚未建立，腳本也會在編譯完成後為您自動建立)*
3. 點擊 Unity 編輯器上方的 **▶ (Play)** 按鈕即可立刻暢玩！
